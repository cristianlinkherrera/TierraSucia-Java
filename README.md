# TierraSucia-Java

Aplicación de consola desarrollada en Java para registrar camiones y controlar la cantidad de tierra recibida en un vertedero.

## Funcionalidades

- Registro de patente y carga del camión.
- Validación de datos ingresados.
- Descarga de tierra en el vertedero.
- Retiro de tierra disponible.
- Control de cantidades negativas o inválidas.
- Consulta y modificación de los datos del camión.

## Conceptos aplicados

- Programación Orientada a Objetos.
- Clases y objetos.
- Encapsulamiento.
- Constructores.
- Getters y setters.
- Sobrecarga de métodos.
- Validaciones y excepciones.
- Entrada de datos con Scanner.
- Sobrescritura del método toString().
